# ATM Project

Este proyecto es una simulación de un cajero automático (ATM) desarrollado en Java. El objetivo es proporcionar una interfaz sencilla para realizar operaciones bancarias básicas como consultar saldo, retirar y depositar dinero.

## Funcionalidades

- Consultar saldo
- Retirar dinero
- Depositar dinero
- Autenticación de usuario
- Generación de recibos

## Requisitos

- Java 8 o superior
- IDE como IntelliJ IDEA o Eclipse
- Maven para la gestión de dependencias

## Instalación

1. Clona el repositorio:
    ```bash
    git https://github.com/Omarlsant/java-bank
    ```

2. Navega al directorio del proyecto:
    ```bash
    cd java-bank
    ```

3. Compila el proyecto usando Maven:
    ```bash
    mvn clean install
    ```

## Uso

1. Ejecuta la aplicación:
    ```bash
    java -jar target/java-bank.jar
    ```

2. Sigue las instrucciones en pantalla para autenticarte y realizar operaciones bancarias.
